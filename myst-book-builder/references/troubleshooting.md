# 條件診斷

先保留完整命令、版本、退出碼、日志與失敗輸入；以下都是有對應症狀才採取的本次 run 修正，不是預設設定。不自動升級、安裝、改全域 DNS／代理或結束其他程序。

- **theme 與引擎配對**：靜態匯出報不相容時，先看 JB 錯誤指出的最高支援 myst-to-react 版本，再按官方 release 的版本 ZIP 固定構建副本 `site.template`。記錄下載來源、實際版本及 SHA；保留舊失敗嘗試，不把改副本稱作原樣通過。
- **localhost／IPv4／IPv6**：服務已起而匯出無法連線時，比對實際監聽地址和 exporter URL，測兩者解析與 HTTP。確定是地址族不一致才在該程序設定 `HOST` 和 Node 的 `--dns-result-order=ipv4first`，並先查該版本 `--keep-host` 的 help；不要改系統 hosts 或 DNS。
- **OpenMP／計算庫衝突**：先在指定 Python 最小匯入重現，查庫官方診斷；只對本次程序做可說明的最小環境修正，再核對實際數值。不要通用設定忽略重複 OpenMP，不移植別書的 ML 修補。
- **內核卡住**：記錄本次 kernel ID／程序、啟動與通訊日志、最後成功格和時間。區分仍計算、啟動失敗與 idle 通訊停滯。只重啟本次 kernel／服務，保留成功結果與失敗原因，按來源指紋續跑；不固定每批章數，不把中斷當完成。
- **靜態 widget**：可見互動控制不代表靜態輸出可用。確認圖的 fallback image 真正載入且 PDF 可讀；需重算時在構建副本生成靜態結果並留來源和差異，不能把空容器當圖已渲染。
- **引用及外鏈**：DOI metadata 失敗、來源 URL、AST 正規化 URL 和 hydration 後 href 分開記錄。HTTP 403 等不等於內部引用錯誤，也不能因此聲稱連結可達。只有已重現的錯誤才按來源 URL 在生成副本局部恢復，重跑 QA；不批量改 DOI、不關閉內部連結檢查。`--strict` 是否包含外鏈檢查要查實際版本 help／來源，若有外網限制，保留診斷並用獨立本地 QA 完成內部檢查。
